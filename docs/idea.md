# Идея: ХАРИС (حارس)

**Харис** — арабское название из двух слогов. Переводится как «Страж», «Охранник». Прямо отражает суть игры — ты последний охранник станции.

## Концепция

**Раннер-шутер от 3-го лица на космической станции.** Игрок — охранник заброшенной орбитальной станции «С7-Омега». Станцию захватили неизвестные дроиды. Цель — продержаться 5 волн атак, очистить станцию и победить босса в конце.

**Жанр:** Шутер / Top-down / Survival
**Платформа:** Yandex Games (HTML5, WebGL)
**Тон:** Мрачный sci-fi, изоляция, безнадёжная оборона

## Сеттинг

Орбитальная станция «С7-Омега» — заброшенная исследовательская платформа на окраине системы. Когда-то здесь проводили эксперименты с искусственным интеллектом. Связь с центром потеряна 72 часа назад. Игрок прибывает на станцию как единственный выживший охранник — его задача — удержать центральный модуль до прибытия подкрепления.

**Локация:** Заброшенная космическая станция
- Коридоры с минимальным освещением
- Модуль с искусственной гравитацией (арена)
- Индикаторы, лампы, экраны
- Обзор затруднён — дым, разгерметизация, обломки

## Игровой процесс

### Основной цикл
1. **Зарядка (10 сек):** волна надвигается, игрок может подготовиться, переместиться
2. **Бой:** враги наступают с разных направлений
3. **Перерыв:** между волнами — меню улучшений, подсчёт очков
4. **Повторить ×5:** сложность растёт
5. **Босс:** в конце 5-й волны

### Механики игрока
- **Движение:** WASD / стрелки, свободное перемещение по арене
- **Стрельба:** автоприцел (целится в ближайшего врага автоматически)
- **Рывок (Dash):** Shift, кулдаун 2.5с, короткий рывок в направлении движения
- **Щит:** пассивный, восстанавливается через 5с после получения урона

### Типы врагов (4 типа)
1. **Бегун** — быстрый, слабый, атакует в ближнем бою
2. **Стрелок** — стреляет издалека, медленный
3. **Танк** — медленный, много HP, взрывается при смерти
4. **Мини-босс** — появляется в волне 3, усиленная версия бегуна

### Босс (волна 5)
- **Прототип ИИ «Омега»** — экспериментальный дроид
- 3 фазы:
  1. Фаза 1: стреляет очередями, призывает бегунов
  2. Фаза 2: быстрые рывки по арене, лазерные лучи
  3. Фаза 3: непрерывная стрельба, вращающиеся снаряды
- Поражение → победа → экран завершения

### Система улучшений (между волнами)
Каждое улучшение выбирается из 3 рандомных карточек:

| Категория | Эффекты |
|-----------|---------|
| Урон | +10% урона (стакается) |
| Скорострельность | +10% скорости стрельбы (стакается) |
| Щит | +1 единица щита |
| Скорость | +15% скорости передвижения |
| Рывок | -30% кулдаун рывка |
| Прочность | +1 жизнь |

## Управление

| Действие | Клавиша |
|----------|---------|

| Пауза | Esc |

## Условия победы / поражения

- **Победа:** уничтожить босса (волна 5)
- **Поражение:** жизни на 0 (HP тратятся при потере щита)

## Зрелищность и FX

- Лазерные выстрелы (лучи/лайны)
- Взрывы при уничтожении врагов (частицы)
- Тряска экрана при взрыве танка
- Вспышки попаданий
- Партиклы дыма на фоне
- Неоновое свечение станции
